Java Type Casting ☕

Why does 7 / 2 give 3.0 in Java? 🤔

✅ Widening (int → long → double) is automatic
✅ Narrowing needs an explicit cast and cuts decimals
✅ Too-big values silently wrap: (byte) 130 = -126
✅ Cast before you divide: (double) 7 / 2 = 3.5
