Spring @Scheduled ☕

Run code on a timer in Spring Boot with one annotation.

✅ Add @EnableScheduling or @Scheduled is ignored
✅ fixedRate counts start to start, fixedDelay waits after each run ends
✅ Spring cron has six fields and starts with seconds
✅ One scheduler thread by default, and every app instance runs the job
