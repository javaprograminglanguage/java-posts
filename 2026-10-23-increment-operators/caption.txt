i++ vs ++i in Java ☕

Both add 1, but do they return the same value?

✅ i++ returns the old value, then adds 1
✅ ++i adds 1 first, then returns the new value
✅ i = i++ leaves i unchanged (the +1 is lost)
✅ In a plain for loop, both behave the same
