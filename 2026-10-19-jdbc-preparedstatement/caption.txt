PreparedStatement vs Statement (JDBC) ☕

One string concatenation can expose your whole database.

✅ Building SQL with + opens the door to SQL injection
✅ PreparedStatement uses ? placeholders for values
✅ Values are bound as data, never executed as SQL
✅ ? works for values only, so whitelist column and table names
