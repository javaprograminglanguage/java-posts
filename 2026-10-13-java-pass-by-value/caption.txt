Pass by Value in Java ☕

Java is ALWAYS pass by value. Even for objects.

✅ Primitives: the method gets a copy of the value
✅ Objects: the method gets a copy of the reference
✅ Changing the object's fields is visible to the caller
✅ Reassigning the parameter is NOT visible to the caller
