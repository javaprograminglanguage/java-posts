Singleton Pattern in Java ☕

One class, only one instance. But a lazy singleton can break with threads.

✅ Private constructor + one static instance + getInstance()
✅ A plain lazy null-check is not thread-safe
✅ The holder idiom is lazy and thread-safe
✅ An enum singleton is the simplest and safest default
