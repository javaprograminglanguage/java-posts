Java Array Gotchas ☕

Printing an array gives garbage. Here are the array traps every Java beginner hits.

✅ println(array) prints a type and hash, use Arrays.toString()
✅ equals() on arrays compares identity, use Arrays.equals()
✅ New arrays are pre-filled with 0, false or null
✅ b = a does not copy, use Arrays.copyOf()
