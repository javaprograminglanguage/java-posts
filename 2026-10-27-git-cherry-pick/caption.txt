git cherry-pick Explained ☕

Need just one commit from another branch? Don't merge everything.

✅ cherry-pick copies a single commit to your current branch
✅ The copy gets a new hash
✅ Use -x to record the original commit in the message
✅ On conflict: fix, git add, then --continue (or --abort)
