Java Ternary Operator (? :) ☕

A one-line if-else, but it hides two classic traps.

✅ Syntax: condition ? ifTrue : ifFalse
✅ Great for simple choices, avoid deep nesting
✅ true ? 1 : 2.0 prints 1.0 (types get promoted)
✅ A null Integer in a ternary can throw an NPE
