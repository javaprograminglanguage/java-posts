How Garbage Collection Works in Java ☕

Java frees memory for you, but how does it decide what to remove?

✅ Objects with no path from a GC root are eligible for collection
✅ Cyclic references don't keep objects alive
✅ System.gc() is only a hint, the JVM decides if and when
✅ Static references can still cause memory leaks
