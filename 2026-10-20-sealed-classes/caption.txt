Sealed Classes in Java ☕

Want to control exactly who can extend your class or interface? Seal it.

✅ sealed + permits lists the only allowed subtypes (final in Java 17)
✅ Every subtype must be final, sealed or non-sealed
✅ A switch over a sealed type needs no default (pattern matching, Java 21)
✅ Add a new subtype and the compiler flags every switch you forgot
