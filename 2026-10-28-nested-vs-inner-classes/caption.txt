Static Nested vs Inner Classes ☕

A class inside a class. Which kind do you have?

✅ Static nested classes need no Outer object
✅ Inner classes are tied to one Outer object
✅ Both can read Outer's private fields
✅ An inner class may keep its Outer alive, so prefer static
