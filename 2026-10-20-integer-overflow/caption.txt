Integer Overflow in Java ☕

Integer.MAX_VALUE + 1 is negative, and Java will not warn you.

✅ int has 32 bits, so past the max it wraps to the minimum
✅ 1_000_000 * 1_000_000 is computed as int first, even if you store it in a long
✅ Math.addExact() and multiplyExact() throw ArithmeticException on overflow
✅ Use long or BigInteger when values can get big
