git reset: soft vs mixed vs hard ☕

Made a wrong commit? Here is how to undo it without panic.

✅ --soft undoes the commit, keeps changes staged
✅ --mixed (default) keeps changes but unstages them
✅ --hard throws your changes away, so be careful
✅ Already pushed? Prefer git revert on shared branches
