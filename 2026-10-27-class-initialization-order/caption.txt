Class Initialization Order in Java ☕

Static block, instance block, constructor. Who runs first?

✅ Static blocks run once per class, parent before child
✅ Instance blocks run before the constructor body
✅ The parent constructor always finishes before the child's
✅ Never call overridable methods from a constructor
